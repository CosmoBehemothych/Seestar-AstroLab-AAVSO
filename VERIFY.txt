1. VERIFY SHA-256 CHECKSUM (WINDOWS)
------------------------------------
Before running the installer, verify that the downloaded file matches the
official SHA-256 hash published in SHA256SUMS.txt on GitHub Releases.

PowerShell:
  Get-FileHash .\Seestar_AstroLab_Setup_v1.3.4.exe -Algorithm SHA256

Command Prompt (CMD):
  certutil -hashfile Seestar_AstroLab_Setup_v1.3.4.exe SHA256

Compare the printed 64-character hex string with SHA256SUMS.txt.
If the hashes do not match, DO NOT run the file and re-download it from:
  https://github.com/CosmoBehemothych/Seestar-AstroLab-AAVSO/releases

2. WHY WINDOWS SMARTSCREEN MAY APPEAR
-------------------------------------
This is a free, MIT-licensed open-source project built automatically on
GitHub-hosted Windows runners (.github/workflows/build.yml). Because this installer does not carry a paid commercial code-signing
certificate, Windows Defender SmartScreen may display "Windows protected
your PC" ("Unknown publisher").

If the SHA-256 hash matches SHA256SUMS.txt:
  Click "More info" -> "Run anyway".
