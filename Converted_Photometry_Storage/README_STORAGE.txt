================================================================================
Seestar AstroLab AAVSO (v1.1.0 alpha) — Хранилище сконвертированных данных фотометрии
Папка: Converted_Photometry_Storage
================================================================================

В этом разделе папки с программой автоматически сохраняются все сконвертированные
вами файлы фотометрии ZWO Seestar в формате AAVSO Extended:

1. user_converted_photometry_db.json
   Локальная база данных всех ваших сконвертированных сессий и фотометрических
   точек (JD Mid, MAG, MERR, фильтр, звезда, код обсерватории OBSCODE).
   Используется программой для автоматического построения многослойной кривой
   блеска и отображения вашего личного вклада поверх данных других участников AAVSO.

2. sessions/
   Архив готовых текстовых/CSV-файлов в стандарте AAVSO Extended (#TYPE=EXTENDED),
   сформированных при каждой конвертации.
